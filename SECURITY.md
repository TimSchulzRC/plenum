# Sicherheit

Plenum verarbeitet Anmeldetokens und Nachrichten aus Microsoft Teams. Wenn du eine Sicherheitslücke findest, melde sie bitte vertraulich über [Security Advisories](https://github.com/TimSchulzRC/plenum/security/advisories/new) und nicht als öffentliches Issue.

Hilfreich sind:

- betroffene Version (steht unter „Über Plenum“)
- Schritte, mit denen sich die Lücke nachstellen lässt
- mögliche Folgen, etwa welche Daten abfließen können

Ich melde mich innerhalb einer Woche zurück. Unterstützt wird nur die jeweils neueste Version.
