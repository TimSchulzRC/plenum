# Sicherheit

Teams Everywhere verarbeitet Anmeldetokens und Nachrichten aus Microsoft Teams. Wenn du eine Sicherheitslücke findest, melde sie bitte vertraulich über [Security Advisories](https://github.com/TimSchulzRC/teams-everywhere/security/advisories/new) und nicht als öffentliches Issue.

Hilfreich sind:

- betroffene Version (steht unter „Über Teams Everywhere“)
- Schritte, mit denen sich die Lücke nachstellen lässt
- mögliche Folgen, etwa welche Daten abfließen können

Ich melde mich innerhalb einer Woche zurück. Unterstützt wird nur die jeweils neueste Version.
